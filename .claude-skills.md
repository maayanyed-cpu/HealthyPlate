# Custom skills for this project

A permanent record of the protocols Maayan has taught Claude. Each skill below has a **trigger phrase** that, when used in a message to Claude, invokes the protocol.

> Type **`view skills`** anytime to have Claude read this file back to you.

---

## 1. Feature Gap Analysis

**Trigger:** `Feature Gap Analysis` (or close paraphrases: "audit the project", "what's left")

**What it does:**
1. Scans `public/prototype.html` (design source-of-truth) and the current `app/` implementation.
2. Produces a matrix with these exact columns: `Feature Name | Status | Design Fidelity | Database Connection | Technical Gap`.
3. Ends with 2–3 priority buckets to plan the next sprint.
4. **Persists the result to `backlog.md`** at the repo root, overwriting prior contents (single canonical state, dated `Last updated:` line at the top).

**The Rule of Truth:**
- *Design Fidelity* is `Done` only if the screen matches the prototype's design tokens AND screen-level layout (sage/cream palette, Fraunces serif, 12/20/28/36 radii, soft shadows). The user labels this aesthetic "Organic & Playful." Anything missing components gets `Partial`.
- *Database Connection* is `Done` only if there is an active Prisma call hitting Postgres in the live code path (not mock data, not localStorage).

**Status vocabulary:** `Built` · `Partial` · `Stub` (Coming-soon placeholder) · `Missing`

**Latest output:** `backlog.md`
